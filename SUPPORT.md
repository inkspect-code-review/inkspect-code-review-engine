# Getting help

Start with the README setup and troubleshooting sections. For a reproducible
engine bug, open a GitHub issue using the bug-report form. For a proposed change,
use the feature-request form. Include the engine version, OS and a redacted error.
Never attach API keys, full prompt captures or private repositories.

For hosted Inkspect account, credits or billing questions, use Support inside the
Inkspect app. This repository tracks the standalone engine, not account requests.
For vulnerabilities or credential leaks, follow [SECURITY.md](SECURITY.md).
